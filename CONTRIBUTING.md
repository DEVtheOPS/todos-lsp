# Contributing

`todos-lsp` is a clean-room Rust rewrite.

- `ianlewis/todos` v0.14.0 is a behavioral reference for MVP parity only.
- Do not copy upstream code, tests, fixtures, regexes, prose, or language tables.
- Record provenance for parity fixtures, parser rules, and support tables in `docs/parity/`.
- If work is tainted, delete it and recreate it rather than editing around the contamination.
